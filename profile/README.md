## About

**Commit+** is a native macOS Git client built with Swift and SwiftUI. It aims to be fast, lightweight, and deeply integrated with the platform — filling the gap left by Electron-based GUIs and proprietary tools.

## Key Features

- **Drag & Drop** — Reorder commits, cherry-pick, merge branches, stage files, and more with simple drag & drop.
- **Undo Any Action** — Full undo/redo support across all Git operations.
- **Built-in Conflict Resolution** — Resolve merge conflicts without leaving the app.
- **Worktree Management** — Create, switch, and manage git worktrees visually.
- **Git Flow** — Repository-aware Git Flow, no external CLI required.
- **AI Commit Generation** — Generate commit messages with Apple Intelligence, OpenAI, Gemini, Claude, DeepSeek, or OpenRouter.
- **Terminal Integration** — Open any repo from the terminal with the `commit` CLI.

## Get Started

Download the latest release from [commit-plus/releases](https://github.com/Commit-Plus/commit-plus/releases/latest), or build from source with Xcode 26.2+.

**Requirements:** macOS 26.2+, Git installed on the system.
